# linkedin-carousels

Working repo for Viktor Simunović's LinkedIn posting system (personal profile and Sicknote page).

- `system/`: rules (VOICE.md, MARKERS.md, UTM.md), the weekly RUNBOOK.md, the slide renderer (render.js), the marker scanner (check_markers.py), brand fonts and example slide specs.
- `media/`: carousels waiting for Metricool to copy them. Files are removed as soon as Metricool has its copy.
- `runs/`: one log per week of drafted posts.

Fonts in `system/fonts` (Inter, Fraunces, Archivo) are under the SIL Open Font License.
